# CyberSecurity Portfolio

## Overview

Welcome to my CyberSecurity Portfolio repository.

This repository contains practical cybersecurity projects focused on network security, system security, cloud security, and Governance, Risk, and Compliance (GRC) concepts.

Each project demonstrates hands-on implementation of security tools, automation scripts, security analysis techniques, and real-world defensive security practices.

---

## Projects

### Project 1: Network Reconnaissance & Database Analyzer

**Technologies:**
- Python
- Nmap
- XML Parsing
- MariaDB
- Linux

**Description:**

A Python-based security analysis tool that processes Nmap scan results, extracts network information, identifies open ports and services, and stores scan data in a database for analysis.

**Key Concepts:**

- Network Reconnaissance
- Nmap XML Parsing
- Service Detection
- Database Integration
- Security Data Analysis

---

### Project 2: Network Service Enumeration Tool

**Technologies:**

- Python
- Socket Programming
- Multithreading
- Kali Linux

**Description:**

A Python-based service enumeration tool designed to scan TCP ports, identify running services, capture service banners, and generate automated security reports.

**Key Concepts:**

- TCP Port Scanning
- Service Enumeration
- Banner Grabbing
- Socket Programming
- Thread Synchronization
- Security Assessment
